# HatRock
Vulkan-based game engine that is being actively developed for Humber Polytechnic's Capstone class in the Game Development program.

The initial framework is being built around Vulkan code as it was given to us by professor Scott Fielder, written by him in a way he could explain since it's not easy to fit Vulkan in just 1 semester. Due to that, the code will contain two varying sets of comments as well: those marked with '///' are Scott's comments, and those marked with '//' are ours.

Our current plan is to, based on the Vulkan course, build the engine primarily around graphics capabilities, with potential additions including basic Networking and game AI, all to be added and functional before the end of the next semester in April, with a 3D game demo to top it off with a demonstration.
